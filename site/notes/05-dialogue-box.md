# 05 — dialogue-box

**Lens.** A game's dialogue backlog. Each beat is a box: nameplate, empty portrait slot (no recording exists), the line, the ▼ prompt. Menus are choice lists; chapters are the branches they open.

**Palette.** Night `#0E1533` (page) · Box `#182563` (dialogue box) · Bone `#EDE6D2` (text, frame) · Marigold `#F2B134` (nameplates, prompts, play) · Jade `#6FCFBF` (the voice while it speaks; the trained node) · Dim `#9EA6CC` (meta).

**Type.** Khand (Indian Type Foundry, Latin and Devanagari): thesis, nameplates, chapters, buttons. Martel (Devanagari-first): spoken lines and paragraphs. DM Mono: the typed description, meta lines, flow nodes.

**Signature mechanic.** The mentor's description types itself; its box arrives below with the seed clip. One box is current at a time (bright frame, bobbing ▼): the speaking box, else the first box still crossing the reading line, so every ▼ jump and menu choice lands on the box it opens. Play reveals the words in step with the clip while the portrait slot draws its live spectrum. "Play the scene" chains the five lines. Picking a description replays that character's stored seed and says so.
