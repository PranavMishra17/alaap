# 06 — inspector

**Lens.** Inside the game engine. One editor window designed as an object, not a Unity screenshot: toolbar with Play scene / Stop, Hierarchy (five-line scene, three voices), Viewport, Inspector, and a dock of Voice assets, Render log and Manifest. Reading sections keep the same chrome as docked panels.

**Palette.** Peacock `#173B3C` (case, page background) · Enamel `#EEF0EA` (panels) · Ink `#101C1E` (text, waveform) · Ash `#5F6E6E` (labels) · Genda `#F2B42C` (selection, play, the trained node, played audio) · Sindoor `#C2452C` (the "experimental setting" flag and issue statuses only).

**Type.** Anek Latin (Ek Type) for display: tabs, viewport words, the Readme masthead at width 125. Anek Devanagari for आलाप. IBM Plex Sans body. IBM Plex Mono for property keys, file names, log, manifest.

**Signature mechanic.** The Viewport draws the real waveform of the selected clip, decoded in the browser, with its exact words as subtitle. Selecting anything swaps the waveform and fills the Inspector with measured facts as properties. Play scene runs the five lines in manifest order: row highlight, marigold playhead, log lines. "Replay the minting" types the description back and plays the pre-rendered seed, saying so on screen.

**Tried and removed.** File/Edit menu labels (pointed nowhere). A log timestamp column. Half the viewport hint. A fake Pacing slider in the Inspector, moved to Measured as a labelled illustration.

**Foregrounded.** §8 clips and §5.9 manifest in the hero; §4 as a property grid; §7 as a node graph; §6 as an issues list with plain statuses.
